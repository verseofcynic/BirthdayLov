Put your background music here.

1. Save an MP3 file in this folder and name it: background.mp3
2. That's it — the little music button appears at the top of the page.

If there is no file here, the music button simply hides itself.
Nothing breaks, and no error is shown.

To use a different file name, change "source" under "music" in data/invite.json.
To turn music off completely, set "enabled": false there.
